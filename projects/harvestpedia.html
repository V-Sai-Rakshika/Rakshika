Project Overview

Harvestpedia is an interactive plant-based food reference platform where users can explore fruits, vegetables, herbs, and indoor plants, discover their nutritional benefits, compare nutritional values, and generate AI-powered recipes based on available ingredients.

Tech Stack

HTML CSS JavaScript Node.js Express.js JSON REST APIs

Features

  • Extensive Database:240+ fruits, 180+ vegetables, and 120+ herbs and indoor plants.
  • Extensive Database: 240+ fruits, 180+ vegetables, and 120+ herbs and indoor plants.
  • Live Search: Instantly find fruits, vegetables, and plants.
  • Nutrition Comparator: Compare up to 5 items using interactive charts and tables.
  • Seasonal Guide: Explore produce based on four seasons.
  • AI Recipe Generator: Generate personalised recipes using available ingredients.
  • Detailed Profiles: Explore nutritional information and health benefits.
  • Educational Resources: Learn about nutrition and plant-based health benefits.
  • Responsive Design: Optimised for desktop, tablet, and mobile devices.
